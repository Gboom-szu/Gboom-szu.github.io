java 与 C++比较

发表于 2023-05-29 更新于 2023-06-02

即将入职了，最近开始看<<ON JAVA 8>> 学习JAVA。目前看了4章，感觉到语法上存在与C++不一样的地方，在此记录一下。

基础语法

Java只允许动态分配内存

  • Java将一切都视为对象，但是操作的却是其引用，这一点与python是一样的。只是这个引用可以不指向任何对象，区别于C++。基本数据类型不使用引用。
  • 基本数据类型。Java有boolean, byte, short, int, long, float, double和void共9中数据类型。值得注意的是，Java没有无符号数据类型。基本数据类型可以直接创建自动变量，而不是通过new。

类与面向对象

  • 在类成员的访问权限上，JAVA与C++一样采用public, private和protected三个等级，而权限与C++完全一致。但是，如果不带任何修饰符，则默认为包访问权限，即可以被同一个包（packet）内的其他类访问。
  • C++需要通过virtual将一个函数指定为虚函数，但是在JAVA中默认所有函数都是虚函数，不需要任何修饰符。
