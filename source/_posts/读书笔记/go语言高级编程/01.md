## 关于闭包和循环

从go 1.22起，for循环每一个循环都会重新创建一个变量，所以当闭包捕获循环变量时，每次都捕获了不同的变量。

```go
	for i := 0; i < 3; i++ {
		i := i // 定义一个循环体内局部变量 i
		defer func() { println(i) }()
	}
```

以上函数会输出 2，1，0
